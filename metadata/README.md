# 书目索引目录

此目录是公开的书目元数据，不存账户、邮箱、书架或阅读进度。
`manifest.json` 指向最近一次成功生成的不可变版本；网站只读这个版本。

- `editions/`：供应商版本与原始书目字段，保留 `gutenberg-N` 兼容键。
- `books/`：独立的慢读实体 ID 和来源版本关系。
- `browse/`、`authors/`、`directory.json`：全量分页、语言、作者和类目索引。
- `search/`：完整的词项倒排索引，按 SHA-256 前两位分片。
- `canonical-mappings.json`（可选）：人工核实后的版本到统一作品映射，不按同名自动合并。

GitHub Actions 每日 08:30 UTC 同步 RSS 中的新增/更新书目及逐本 RDF；星期日做 CSV 全量校验。
支持手动运行 Full。失败保留之前的 manifest。整个版本和 manifest 在同一个提交中发布。
正文、共享译文和译文索引继续独立存放于 `books/` 与 `indexes/`。

CSV 只提供每周快照，没有下载热度、版权结论、AI 难度等信息，因此不伪造这些字段。
阅读未知版本时会独立核实 RDF 的来源许可。中文标题、阅读难度、AI 摘要和向量推荐是独立增补层，尚未批量生成。
